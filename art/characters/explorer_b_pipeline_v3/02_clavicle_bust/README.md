# Explorer B 쇄골 흉상 v1

**사용자 정정 후 상태: 별도 도구 테스트로만 보존.** 제작 모델은 Tripo에서 생성하고 Blender로 다듬은 뒤 페이스 리깅 단계에 애드온을 사용합니다. 이 MPFB 흉상은 제작 기준본으로 채택하지 않습니다.

2026-10-04. 무료 MPFB 2.0.17 템플릿에서 만든 디자인·표정 검토용 흉상입니다. 기존 승인 이미지 `art/references/explorer_b_faceit_comparison_v1/03_head_neck_clavicle.png`를 참고했으며, 기존 캐릭터 파일과 원본 템플릿은 덮어쓰지 않았습니다.

## 열기

프로젝트 루트의 `Character_Clavicle_Bust_Blender.cmd`를 실행합니다. Blender 4.5.3과 격리된 face-v3 프로필을 사용합니다. 직접 열 파일은 `explorer_b_clavicle_bust_v1.blend`입니다.

- 1 프레임: 눈을 뜨고 입을 다문 기본 표정.
- Space: 18초 동안 눈 감기, 좌우 시선, 미소, 입 벌리기, 입 오므리기 검토.
- `Face_Neck_Clavicle`의 Shape Keys: 52개 ARKit 표정 + 37개 발음 표정. 눈·눈썹·속눈썹·치아·혀는 해당 키에 연동됩니다.

## 구조와 검증

피부는 머리부터 목과 쇄골 밑단까지 연결된 하나의 메시입니다. 밑단은 실제 폴리곤을 잘라 연결하고 지지 루프를 넣어 닫았습니다. 베이스 피부 4,635 버텍스, 4,609 면이며, 표시용 Subdivision 1단계는 적용하지 않고 유지합니다. 눈꺼풀은 얼굴 피부의 일부이고 속눈썹은 별도 메시입니다.

정면·3/4·측면, 눈 감기, 미소, 입 벌리기를 렌더링했습니다. 저장 파일을 다시 열어 피부 연결성, 닫힌 경계, 유한 좌표, 표정 키 및 부속 메시 드라이버를 검사하고 중간 깜빡임과 시선 결합을 추가 렌더링했습니다. 상세 결과는 `artifacts/mpfb-clavicle-bust-20261004/verification.json`에 있습니다.

이번 흉상은 표정 셰이프키로 구동되며 독립된 본 리그는 포함하지 않습니다. 원본 템플릿의 Rigify 테스트 파일은 별도로 유지됩니다. 모든 표정 조합의 조형 품질이나 게임 내 동작을 검증한 최종 모델은 아닙니다. 기존 디자인과의 인상·비율은 사용자 검토가 필요합니다. Tripo 등 유료 API 사용은 0회입니다.
