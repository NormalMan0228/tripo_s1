# phrase that starts with a listed word. Swear words come from chat_words.txt (category words, Korean

# the LLM designer, and Tripo's own content check backs both up.

# Hangul entries match at the START of a word (spaces between words ignored: "잘린 머리" = 잘린머리),
# never inside one, so 바나나체어 is not 나체 and 처음부터 is not 음부. Still left out because they
# start ordinary words: 성기 (성기사), 참수 (참수리), 시신 (시신경), 고어 (고어 문자), 마약 alone
# (마약 방석, 마약 침대...: the LLM judges it). Latin entries are whole words (plurals included),
# `word*` also as a word's start, two words a phrase.
