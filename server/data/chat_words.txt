# Villagen chat word list (server/chat_filter.py). Plain text, one entry per line, reviewed by hand.
# An operator adds words without a code change in a second file of the same syntax
# (VILLAGEN_CHAT_FILTER_EXTRA, relative to the data directory), read when the server starts.
#
#   word      masked with * (Hangul: anywhere in a line, also split by spaces, digits or dots;
#             Latin: as a whole word, plural -s/-es included)
#   word*     Latin only: also inside longer words (fuck* masks "motherfucker")
#   two words Latin phrase, matched with the spaces removed ("kill yourself")
#   !word     the whole line is refused (message_blocked) instead of masked
#   +phrase   an allowed phrase: a match that lies inside it is left alone (시발점, 다시발)
#
# Matching ignores case, full-width letters, zero-width characters, and spaces, dots or digits
# between letters, so "시 1 발", "ㅅ.ㅂ" and "f u c k" are caught. A split across a plain space only
# counts when the first letter starts a word, so "다시 발견" stays readable.
# Left out on purpose (too many false positives in ordinary Korean): 보지 (보지 마), 자지 (자지 마),
# 꺼져 (불이 꺼져), 졸라 (엄마를 졸라서), 새끼 alone (새끼 고양이), 미친 alone, 씹 alone (씹다),
# 시바 (시바견).
