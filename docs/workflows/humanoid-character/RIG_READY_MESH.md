# 페이스 리깅 시작용 메시 기준

우리에게 필요한 산출물은 디테일 부위를 개별 편집할 수 있고, 얼굴 피부가 자연스럽게 변형되는 메시입니다. Tripo 원형의 디자인을 유지하면서 구조를 정리한 뒤 Faceit 또는 Rigify에 넘깁니다. 2026년 10월 5일 이 채팅에서 추가한 제작 요구사항입니다.

## 파츠 구성

| 구성 | 분리와 연결 기준 | 리깅에서의 역할 |
|---|---|---|
| 머리와 얼굴 피부 | 코·볼·턱·입술·위아래 눈꺼풀·귀를 연결된 피부로 구성. 각 영역은 버텍스 그룹이나 선택 영역으로 편집 | 웃음·입 벌림·깜빡임에서 주변 피부와 함께 변형 |
| 좌우 안구 | 각각 독립 오브젝트 | 독립 시선 회전과 안구 재질 |
| 좌우 눈썹 | 각각 독립 오브젝트 | 눈썹·이마 표정 추종 |
| 좌우 위아래 속눈썹 | 총 네 역할을 구분해 독립 편집 | 대응 눈꺼풀 변형 추종 |
| 위 치열과 잇몸 | 위쪽 그룹으로 관리 | 상악 기준 추종 |
| 아래 치열과 잇몸 | 위쪽과 독립된 아래쪽 그룹 | 턱 움직임 추종 |

| 구강과 입술 안쪽 | 피부와 접합되는 내부 구조와 충분한 깊이 확보 | 입 벌림에서 틈·찢김·바깥 피부 비침 방지 |
| 헤어와 장식 | 피부와 독립. 필요에 따라 앞·옆·뒤 묶음 관리 | 머리 추종·교체·간섭 검수 |

치아를 개별 편집할 필요가 있으면 위·아래 컬렉션 안에서 개별 오브젝트로 유지할 수 있습니다. 최종 바인딩에서는 움직임 역할에 따라 그룹을 지정합니다. 얼굴 피부의 코·입술·눈꺼풀을 각각 떨어진 조각으로 나누는 것을 상세 편집의 목표로 삼지 않습니다.

Faceit 공식 문서는 별도 오브젝트와 한 오브젝트 안의 부품을 모두 처리할 수 있다고 설명합니다. 주요 얼굴 피부는 연결된 표면이어야 합니다. 우리의 독립 오브젝트 구성은 편집·교체·역할 구분을 위한 제작 기준입니다. [Faceit Geometry](https://faceit-doc.readthedocs.io/en/latest/geometry/)

## 리깅 전에 통과할 기준

1. 눈과 입 주변에 변형을 따라가는 엣지 흐름이 있고, 눈꺼풀과 입술의 안쪽 두께를 확인할 수 있어야 합니다. 쿼드 개수만으로 통과하지 않습니다.
2. 중복 정점·겹친 면·불필요 조각·뒤집힌 면을 정리합니다. 열린 경계는 목 절단 등 의도된 경계와 결함을 구분해 기록합니다.
3. 정면·사선·측면에서 기본 얼굴 인상, 안구 위치, 눈꺼풀 틈, 입술과 턱의 실루엣을 검토합니다.
4. 리깅 기준형은 눈을 편안하게 뜨고 입을 다문 중립 상태로 준비합니다. 사용자가 요청한 약한 미소는 별도 평소 표정 프리셋으로 보존합니다.
5. 눈·눈썹·속눈썹·위 치열·아래 치열·혀의 좌우와 역할을 이름·컬렉션·그룹으로 구분합니다. 회전 중심과 배치도 기록합니다.
6. 대칭 제작 원본은 보존하고, 리깅용 복사본에서는 Mirror와 변형 모디파이어를 선택한 애드온의 요구에 맞춰 정리합니다. 기존 임시 Shape Key가 있으면 모디파이어 적용으로 손상되지 않도록 별도로 보존합니다.
7. 기존 모션을 끄고 몸 리그를 Rest Position에 둡니다. 얼굴과 몸에서 같은 머리 회전을 중복 적용하지 않도록 합니다.
8. 최종 Shape Key 제작에 들어가는 피부 메시의 정점 수·순서를 안정시킵니다. 이후 구조 변경은 별도 버전에서 처리하고 표정 전이·재작성 여부를 기록합니다.

중립 표정·모디파이어 정리·Rest Position·깨끗한 토폴로지는 Faceit의 공식 준비 항목입니다. 기존 제작 원본의 앞 +X / 위 +Z / 좌우 Y 규격과 Faceit 문서의 앞 -Y 규격은 다릅니다. **Faceit 바인딩용 복사본을 해당 방향에 맞추고 변환 정보를 남기며, 원본 좌표 규격은 보존**합니다. [Faceit 준비 조건](https://faceit-doc.readthedocs.io/en/latest/geometry/)

## 산출물과 검수 범위

- 디자인·고밀도 생성 원본과 작업 이력을 보존합니다.
- 별도로 리깅 준비용 Blender 파일과 파츠·역할 대응표를 남깁니다.
- 기본 얼굴의 정면·사선·측면·눈·입 확대와 내부 단면을 제공합니다.
- 형상·연결·정점·모디파이어·역할 그룹의 검사 결과와 사용자 검토를 기록합니다.
- 이후 리깅 단계에서 깜빡임·입 벌림·미소를 시험하고 눈꺼풀·속눈썹·입안 추종을 확인합니다. 준비 메시 검수와 리그 변형 검수는 별도 상태입니다.
