# [Domain Knowledge] AI-Driven 3D Character Pipeline (Face & Hair)

## 1. Overview
Modern 3D character pipelines divide Face and Hair workflows due to different physical and rendering requirements. AI tools are actively replacing manual topology, rigging, and animation tasks.

## 2. Face Pipeline
- **Modeling & Generation:**
  - `Mesh to MetaHuman` (Unreal): Converts scan/dummy meshes to AAA topology with UVs/Textures via ML.
  - `KeenTools FaceBuilder` (Blender/Nuke): Generates realistic face meshes and textures from 2D photos.
  - `Rodin` / `Tripo3D`: Generates 3D head meshes directly from text/image prompts.
- **Rigging (Automated):**
  - `Faceit` (Blender): Semi-automated AI fitting of 52 ARKit facial blendshapes.
  - `MetaHuman DNA` / `AccuRig`: AI-based automated bone/joint placement and skin weighting.
- **Performance & Animation:**
  - `NVIDIA Audio2Face`: Standard for audio-driven multi-lingual lip-sync and facial expressions.
  - `Live Link Face` / `Wonder Dynamics`: Markerless facial mocap and retargeting from single RGB video.

## 3. Hair Pipeline
- **Modeling & Grooming:**
  - `AI Hair Card Generators`: Converts raw voxel/mesh hair (from tools like Rodin) into game-ready hair cards or curves.
  - `MetaHuman Groom`: Automated strand fitting to skull curvature.
- **Rigging & Physics Simulation:**
  - `Unreal Engine ML Deformer`: Machine learning model for real-time, lightweight hair/cloth physics simulation, preventing mesh intersections.
  - `Cascadeur`: AI-assisted physics animation tool. Calculates realistic secondary motion (hair, accessories) based on primary body movement.

## 4. Dominant Workflows by Ecosystem
| Ecosystem | Target User | Toolchain Sequence (Modeling -> Rigging -> Animation) |
| :--- | :--- | :--- |
| **Blender (Indie)** | Solo Devs, Indie | Rodin/FaceBuilder -> Faceit -> Audio2Face + Cascadeur |
| **Unreal (Real-time)** | AAA Studios, VP | Mesh to MetaHuman -> MetaHuman DNA -> Live Link Face -> ML Deformer |
