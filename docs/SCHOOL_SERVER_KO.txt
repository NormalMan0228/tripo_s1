Villagen 학교 서버 (AWS 서울) 만들기
=====================================

심사 서버(미국 GCP, 34-28-65-113.sslip.io)는 그대로 둡니다. 학교 서버는 AWS 서울 리전에 새로 만들고, 코드는 dev 브랜치를 씁니다.
· 【명령】 표시가 붙은 줄만 서버 창에 붙여넣습니다. 나머지는 설명입니다.
· 키(Tripo, Gemini)는 서버에만 저장합니다. 채팅, Git, ZIP에는 넣지 않습니다.

------------------------------------------------------------
0단계. AWS 가입과 비용 (명령 없음)
------------------------------------------------------------
· aws.amazon.com에서 가입합니다(카드 인증 필요). 가입할 때 [무료 플랜]을 고르면 크레딧을 다 쓰거나 6개월이 지나도 요금이 청구되지 않습니다. 대신 그때 계정이 닫히고, 90일 안에 유료로 바꾸지 않으면 데이터가 지워집니다.
· 신규 계정은 크레딧 $100를 받고, 콘솔 첫 화면의 'Explore AWS' 활동을 하면 $100를 더 받습니다(EC2 실행, Budgets 설정 등 아래에서 어차피 하는 일이 포함).
· 예상 비용: t4g.small 월 약 $15, 공인 IP 월 약 $3.6, 디스크 20GB 월 약 $2 → 월 약 $21. 크레딧 $200이면 6개월을 버티고, $100만 있으면 약 4~5개월입니다. 정확한 금액은 AWS 요금 계산기에서 확인하세요.
· (권장) 결제 및 비용 관리 → Budgets에서 월 $25 예산 알림을 만들어 두면 크레딧이 줄어드는 속도를 메일로 받습니다.
· 콘솔 오른쪽 위 리전을 [아시아 태평양(서울) ap-northeast-2]로 바꿉니다.

------------------------------------------------------------
1단계. 서버 만들기 (EC2 콘솔, 명령 없음)
------------------------------------------------------------
EC2 → 인스턴스 → [인스턴스 시작]
  · 이름: villagen-school
  · 이미지(AMI): Ubuntu Server 24.04 LTS, 아키텍처 [64비트(Arm)]
  · 인스턴스 유형: t4g.small (vCPU 2, 메모리 2GB). 학과 인원이 많으면 t4g.medium(4GB, 비용 2배)
  · 키 페어: [키 페어 없이 계속]을 골라도 됩니다(브라우저 접속을 씁니다)
  · 네트워크 설정: [SSH 트래픽 허용], [인터넷에서 HTTPS 트래픽 허용], [인터넷에서 HTTP 트래픽 허용]을 모두 체크
  · 스토리지: 20GiB gp3
  · [인스턴스 시작]

고정 주소 붙이기 (꼭 하세요, 2단계보다 먼저):
EC2 → 네트워크 및 보안 → 탄력적 IP → [탄력적 IP 주소 할당] → [할당] → 만든 주소 선택 → 작업 → [탄력적 IP 주소 연결] → 인스턴스 villagen-school 선택 → [연결]
이렇게 해야 서버를 껐다 켜도 주소가 바뀌지 않습니다. 게임에 넣는 주소가 이 주소로 정해집니다.

------------------------------------------------------------
2단계. 접속해서 설치 (처음 한 번)
------------------------------------------------------------
인스턴스 선택 → [연결] → [EC2 Instance Connect] 탭 → 사용자 이름 ubuntu → [연결]. 브라우저에 검은 창이 열립니다. 아래 줄을 하나씩 붙여넣습니다(붙여넣기: Ctrl+Shift+V 또는 우클릭).

【명령】 sudo apt-get update && sudo apt-get install -y git
【명령】 git clone -b dev https://github.com/NormalMan0228/tripo_s1.git ~/tripo_s1
【명령】 cd ~/tripo_s1
【명령】 sudo bash ops/bootstrap-gcp-free.sh

마지막 줄에서 Docker 설치, 서버 실행, HTTPS 주소(탄력적 IP를 -로 이은 주소.sslip.io)를 자동으로 준비합니다. 처음에는 몇 분 걸립니다. 끝에 나오는 "Demo URL: https://...sslip.io/health" 줄의 주소를 저에게 알려 주세요. 그 주소를 학교 빌드에 넣겠습니다.

"Could not find the public IP"가 나오면 탄력적 IP 주소를 넣어 다시 실행합니다(예: 3.38.12.34):
【명령】 sudo PUBLIC_IP=3.38.12.34 bash ops/bootstrap-gcp-free.sh

------------------------------------------------------------
3단계. 키 파일 저장 (각각 한 줄)
------------------------------------------------------------
【명령】 sudo nano ops/secrets/tripo-key
Tripo 키를 붙여넣고(브라우저 SSH는 Ctrl+Shift+V 또는 우클릭) Ctrl+O → Enter → Ctrl+X로 저장합니다. 키가 여러 개면 한 줄에 하나씩 넣습니다.

【명령】 sudo nano ops/secrets/gemini-key
Gemini 키를 같은 방법으로 저장합니다.

------------------------------------------------------------
4단계. 학교 규칙으로 켜기
------------------------------------------------------------
【명령】 sudo bash ops/update_online_server.sh dev --open-signup --per-account 0 --per-day 3 --craft-day-limit 105 --max-credits 35 --budget 4000 --welcome-stars 70

뜻 (순서대로):
  · dev: 학교 개발 브랜치를 받아 서버를 다시 만듭니다
  · --open-signup: 초대 코드 없이 가입할 수 있습니다
  · --per-account 0: 계정별 평생 제작 횟수 제한이 없습니다. 대신 하루 제한과 전체 예산으로 막습니다
  · --per-day 3: 한 계정이 하루에 맡길 수 있는 제작 수입니다
  · --craft-day-limit 105: 서버 전체에서 하루에 맡길 수 있는 제작 수입니다
  · --max-credits 35: 한 번 제작에 쓸 수 있는 Tripo 크레딧입니다(색 입힌 가구 20, 사진+색 30, 사진 다듬기+색 35)
  · --budget 4000: 이 서버가 쓸 수 있는 Tripo 크레딧 총량입니다. 다 쓰면 게임에 "이번 학기 제작 예산을 모두 썼어요"가 뜨고 제작이 멈춥니다
  · --welcome-stars 70: 새 계정에 처음 주는 별씨입니다(직접 색칠 20, 움직이는 가구 30, 색 입힘 40)
마지막에 health 결과가 "ok": true로 나오면 끝입니다.

------------------------------------------------------------
이후 업데이트 (코드가 바뀌었을 때)
------------------------------------------------------------
【명령】 cd ~/tripo_s1
【명령】 sudo bash ops/update_online_server.sh dev --open-signup --per-account 0 --per-day 3 --craft-day-limit 105 --max-credits 35 --budget 4000 --welcome-stars 70

예산 확인: 브라우저에서 https://<학교 서버 주소>/health 를 열면 "tripo_budget": {"used": 사용량, "total": 4000} 이 보입니다. 업데이트 명령 끝에도 같은 줄이 나옵니다. 예산을 늘리려면 --budget 숫자를 바꿔 위 명령을 다시 실행합니다. 늘리기 전에 사용할 크레딧 양을 먼저 정해 주세요.
