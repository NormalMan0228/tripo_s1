Villagen 학교 서버 (서울 VM) 만들기
====================================

심사 서버(미국, 34-28-65-113.sslip.io)는 그대로 둡니다. 학교 서버는 서울에 새로 만들고, 코드는 dev 브랜치를 씁니다.
· 【명령】 표시가 붙은 줄만 VM 창에 붙여넣습니다. 나머지는 설명입니다.
· 키(Tripo, Gemini)는 VM에만 저장합니다. 채팅, Git, ZIP에는 넣지 않습니다.

------------------------------------------------------------
1단계. VM 만들기 (Google Cloud 콘솔, 명령 없음)
------------------------------------------------------------
Compute Engine → VM 인스턴스 → [인스턴스 만들기]
  · 이름: villagen-school
  · 리전: asia-northeast3 (서울), 영역: 아무거나
  · 머신: e2-small (vCPU 2, 메모리 2GB). 학과 인원이 많으면 e2-medium(4GB)
  · 부팅 디스크: [변경] → Debian 12 (bookworm), 크기 20GB
  · 방화벽: [HTTP 트래픽 허용]과 [HTTPS 트래픽 허용]을 모두 체크
  · [만들기]
비용: 무료 등급이 아닙니다. e2-small은 대략 월 $15 안팎이고, 공인 IP 비용이 조금 더 붙습니다. 정확한 금액은 만들기 화면 오른쪽 예상 비용에서 확인하세요.
권장: VPC 네트워크 → IP 주소에서 이 VM의 외부 IP를 [고정 주소로 승격]합니다. 승격하지 않으면 VM을 다시 켤 때 주소가 바뀌어 게임에 넣은 주소도 바꿔야 합니다.

------------------------------------------------------------
2단계. 접속해서 설치 (처음 한 번)
------------------------------------------------------------
VM 줄의 [SSH] 버튼을 누르면 브라우저 창이 열립니다. 아래 줄을 하나씩 붙여넣습니다.

【명령】 sudo apt-get update && sudo apt-get install -y git
【명령】 git clone -b dev https://github.com/NormalMan0228/tripo_s1.git ~/tripo_s1
【명령】 cd ~/tripo_s1
【명령】 sudo bash ops/bootstrap-gcp-free.sh

마지막 줄에서 Docker 설치, 서버 실행, HTTPS 주소(외부IP를 -로 이은 주소.sslip.io)를 자동으로 준비합니다. 끝에 나오는 "Demo URL: https://...sslip.io/health" 줄의 주소를 저에게 알려 주세요. 그 주소를 학교 빌드에 넣겠습니다.

------------------------------------------------------------
3단계. 키 파일 저장 (각각 한 줄)
------------------------------------------------------------
【명령】 sudo nano ops/secrets/tripo-key
Tripo 키를 붙여넣고(브라우저 SSH는 Ctrl+Shift+V 또는 우클릭) Ctrl+O → Enter → Ctrl+X로 저장합니다. 키가 여러 개면 한 줄에 하나씩 넣습니다.

【명령】 sudo nano ops/secrets/gemini-key
Gemini 키를 같은 방법으로 저장합니다.

------------------------------------------------------------
4단계. 학교 규칙으로 켜기
------------------------------------------------------------
【명령】 sudo bash ops/update_online_server.sh dev --open-signup --per-account 0 --per-day 10 --craft-day-limit 100 --max-credits 30 --budget 2000 --welcome-stars 300

뜻 (순서대로):
  · dev: 학교 개발 브랜치를 받아 서버를 다시 만듭니다
  · --open-signup: 초대 코드 없이 가입할 수 있습니다
  · --per-account 0: 계정별 평생 제작 횟수 제한이 없습니다. 대신 하루 제한과 전체 예산으로 막습니다
  · --per-day 10: 한 계정이 하루에 맡길 수 있는 제작 수입니다
  · --craft-day-limit 100: 서버 전체에서 하루에 맡길 수 있는 제작 수입니다
  · --max-credits 30: 한 번 제작에 쓸 수 있는 Tripo 크레딧입니다(색 입힌 가구 20, 사진+색 30)
  · --budget 2000: 이 서버가 쓸 수 있는 Tripo 크레딧 총량입니다. 다 쓰면 게임에 "이번 학기 제작 예산을 모두 썼어요"가 뜨고 제작이 멈춥니다
  · --welcome-stars 300: 새 계정에 처음 주는 별씨입니다(색 입힌 제작은 1회 별씨 40)
마지막에 health 결과가 "ok": true로 나오면 끝입니다.

------------------------------------------------------------
이후 업데이트 (코드가 바뀌었을 때)
------------------------------------------------------------
【명령】 cd ~/tripo_s1
【명령】 sudo bash ops/update_online_server.sh dev --open-signup --per-account 0 --per-day 10 --craft-day-limit 100 --max-credits 30 --budget 2000 --welcome-stars 300

예산 확인: 브라우저에서 https://<학교 서버 주소>/health 를 열면 "tripo_budget": {"used": 사용량, "total": 2000} 이 보입니다. 업데이트 명령 끝에도 같은 줄이 나옵니다. 예산을 늘리려면 --budget 숫자를 바꿔 위 명령을 다시 실행합니다. 늘리기 전에 사용할 크레딧 양을 먼저 정해 주세요.
