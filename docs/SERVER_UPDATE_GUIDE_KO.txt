온라인 서버 업데이트 안내 (심사용)
==================================

이 안내대로 하면 심사위원이 받은 게임 ZIP으로 온라인에 접속해
물건 제작(서버 → Gemini 설계 → Tripo 3D)까지 할 수 있습니다.
걸리는 시간: 약 15분. 명령은 복사해서 붙여넣기만 하면 됩니다.

주의: API 키와 초대 코드는 서버에만 둡니다. 채팅·메일·GitHub에 올리지 마세요.


[준비] 키 두 개
---------------
1. Gemini 키 (AI 설계, 무료)
   - https://aistudio.google.com/apikey 접속 → Google 계정으로 로그인
   - "Create API key" 버튼 → 만들어진 키 옆의 복사 버튼
   - 메모장에 잠깐 붙여 두세요 (작업이 끝나면 지웁니다).

2. Tripo 키 (3D 생성)
   - 이 PC 바탕화면의 tripo_key.txt 를 메모장으로 열어 키 한 줄을 복사해 둡니다.


[1단계] 서버(VM) 창 열기
------------------------
1. https://console.cloud.google.com 접속 → 왼쪽 메뉴 "Compute Engine" → "VM 인스턴스"
2. 데모 서버 줄 오른쪽의 "SSH" 버튼을 누릅니다.
3. 검은 창(터미널)이 새로 열리면 준비 완료입니다.

붙여넣기: 검은 창에서 Ctrl+Shift+V 또는 마우스 오른쪽 클릭.


[2단계] 저장소 폴더로 이동
--------------------------
아래를 붙여넣고 Enter:

    cd ~/tripo_s1

"No such file or directory"가 나오면 아래로 위치를 찾은 뒤, 출력된 경로에서
끝의 /ops/update_online_server.sh 를 뺀 폴더로 cd 합니다.

    sudo find / -name update_online_server.sh -path '*ops*' 2>/dev/null


[3단계] 최신 코드 받기
----------------------
한 줄씩 붙여넣고 Enter:

    sudo git fetch origin
    sudo git checkout main
    sudo git pull --ff-only origin main

※ 오류가 나면 main 대신 island-village-rpg 를 넣어 세 줄을 다시 실행하고,
  5단계 명령의 main 도 island-village-rpg 로 바꿉니다.


[4단계] 키 파일 저장
--------------------
(1) Tripo 키

    sudo nano ops/secrets/tripo-key

  - 화면이 바뀌면 Tripo 키를 붙여넣습니다.
  - 저장: Ctrl+O → Enter / 나가기: Ctrl+X
  - 이미 예전에 넣었다면 그대로 두고 Ctrl+X 로 나가도 됩니다.

(2) Gemini 키

    sudo nano ops/secrets/gemini-key

  - Gemini 키를 붙여넣고 Ctrl+O → Enter → Ctrl+X


[5단계] 업데이트 실행 — 아래 두 방식 중 하나만 고르세요
-------------------------------------------------------
작은 서버라 몇 분 걸립니다. 끝에 /health 결과가 한 줄 나오면 끝입니다.

  방식 A) 초대 코드가 있어야 가입 (가장 안전)

    sudo bash ops/update_online_server.sh main --per-account 3 --per-day 1000 --welcome-stars 150 --invite-only

  방식 B) 초대 코드 없이 누구나 가입 (공개 가입)

    sudo bash ops/update_online_server.sh main --per-account 3 --per-day 1000 --craft-day-limit 30 --welcome-stars 150 --open-signup

  옵션 뜻
  - --per-account 3     : 계정 하나당 제작은 평생 3번
  - --welcome-stars 150 : 새 계정이 별씨 150개로 시작 → 바로 제작해 볼 수 있음
  - --per-day 1000      : 하루 제작 한도 사실상 없음 (방식 A)
  - --craft-day-limit 30: 서버 전체 하루 제작 30번까지 (방식 B에서 크레딧 보호용,
                          하루 최대 약 2,400 크레딧)
  - --open-signup       : 초대 코드 없이 가입 허용 (같은 주소에서 하루 3계정, 하루 전체 200계정까지)
  - --invite-only       : 초대 코드가 있어야 가입

  방식 B를 쓰면 GitHub의 게임 ZIP을 받은 누구나 가입할 수 있으므로, 하루 제작 한도로
  Tripo 크레딧이 지켜집니다. 심사가 끝나면 방식 A 명령으로 다시 닫을 수 있습니다.


[6단계] 성공 확인
-----------------
마지막 줄에 다음 글자들이 보이면 성공입니다.

    "version":"0.10.0"
    "studio_tripo_enabled":true
    "studio_llm":"gemini"
    "open_registration":true   (방식 B일 때) / false (방식 A일 때)

웹 브라우저로 https://34-28-65-113.sslip.io/health 를 열어도 같은 내용을 볼 수 있습니다.


[7단계] 심사위원에게 보내기
--------------------------
- 게임 받기: https://github.com/NormalMan0228/tripo_s1/releases/tag/v0.10.0
  → Tripothon_v0.10.0_Windows.zip 을 받아 압축을 풀고 Tripothon.exe 실행
- 방식 A라면 초대 코드도 함께 보냅니다. 코드 확인 명령:

    sudo cat ops/secrets/registration-code

- 방식 B라면 초대 코드 칸은 비워 두고 가입하면 됩니다.


[문제가 생기면]
---------------
- 6단계 글자가 안 보일 때: 아래 명령의 출력을 복사해 Claude에게 보여 주세요.
  (키 값은 출력되지 않습니다)

    sudo docker compose --env-file ops/production.env -f ops/compose.yaml -f ops/compose.gcp-free.yaml -f ops/compose.tripo.yaml -f ops/compose.gemini.yaml logs api --tail 80

- 제작이 실패하고 잠시 뒤 다시 되는 경우: Gemini 무료 등급의 분당 한도입니다. 정상입니다.
- 키를 바꾸고 싶을 때: 4단계에서 파일만 고친 뒤 5단계 명령을 다시 실행합니다.
- 한도를 바꾸고 싶을 때: 5단계 명령의 숫자만 바꿔 다시 실행합니다.

작업이 끝나면 메모장에 붙여 둔 키는 지워 주세요.
