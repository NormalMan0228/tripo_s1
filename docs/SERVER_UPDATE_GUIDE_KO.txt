온라인 서버 업데이트 안내 (체험판·심사용)
=========================================

이 안내대로 하면 게임 ZIP을 받은 사람 누구나 초대 코드 없이 가입해
물건 제작(서버 → Gemini 설계 → Tripo 3D)까지 해 볼 수 있습니다.
걸리는 시간: 약 15분. 명령은 복사해서 붙여넣기만 하면 됩니다.

체험판 규칙 (서버가 지킵니다)
- 가입: 초대 코드 없음. 같은 인터넷 주소에서 하루 3계정, 하루 전체 200계정까지.
- 제작: 계정당 평생 3번, 1번에 Tripo 최대 10크레딧(색칠용 · 정적인 가구 · H3 한 덩어리).
- 서버 전체 제작: 하루 30번까지 → Tripo는 하루 최대 300크레딧.
- 새 계정은 별씨 150개로 시작해 바로 제작해 볼 수 있습니다.

주의: API 키는 서버에만 둡니다. 채팅·메일·GitHub에 올리지 마세요.


[준비] 키 두 개
---------------
1. Gemini 키 (AI 설계, 무료)
   - https://aistudio.google.com/apikey 접속 → Google 계정으로 로그인
   - "Create API key" 버튼 → 만들어진 키 옆의 복사 버튼
   - 메모장에 잠깐 붙여 두세요 (작업이 끝나면 지웁니다).

2. Tripo 키 (3D 생성) — 여러 개 가능
   - 이 PC 바탕화면의 tripo_key.txt 를 메모장으로 열어 키를 복사해 둡니다.
   - Tripo 계정이 여러 개라면 각 계정의 키를 모두 준비합니다.
     서버는 맨 위 키부터 쓰다가 크레딧이 모자라면 자동으로 다음 키를 씁니다.


[1단계] 서버(VM) 창 열기
------------------------
1. https://console.cloud.google.com 접속 → 왼쪽 메뉴 "Compute Engine" → "VM 인스턴스"
2. 데모 서버 줄 오른쪽의 "SSH" 버튼을 누릅니다.
3. 검은 창(터미널)이 새로 열리면 준비 완료입니다.

붙여넣기: 검은 창에서 Ctrl+Shift+V 또는 마우스 오른쪽 클릭.


[2단계] 저장소 폴더로 이동
--------------------------
아래를 붙여넣고 Enter:

    cd ~/tripo_s1

"No such file or directory"가 나오면 아래로 위치를 찾은 뒤, 출력된 경로에서
끝의 /ops/update_online_server.sh 를 뺀 폴더로 cd 합니다.

    sudo find / -name update_online_server.sh -path '*ops*' 2>/dev/null


[3단계] 최신 코드 받기
----------------------
한 줄씩 붙여넣고 Enter:

    sudo git fetch origin
    sudo git checkout main
    sudo git pull --ff-only origin main


[4단계] 키 파일 저장
--------------------
(1) Tripo 키 (한 줄에 키 하나, 여러 줄 가능)

    sudo nano ops/secrets/tripo-key

  - 화면이 바뀌면 Tripo 키를 붙여넣습니다. 키가 여러 개면 한 줄에 하나씩:

        첫번째_키
        두번째_키
        세번째_키

    맨 위 키를 먼저 쓰고, 그 계정의 크레딧이 모자라면 다음 줄 키를 씁니다.
    # 로 시작하는 줄은 메모로 무시됩니다. (예: # 친구 계정)
  - 저장: Ctrl+O → Enter / 나가기: Ctrl+X
  - 이미 예전에 넣었다면 키를 아랫줄에 추가하기만 하면 됩니다.
  - 이미 만들어지고 있던 물건은 처음 쓴 키로 끝까지 마무리됩니다.
  - 서버는 계정마다 안전 여유분 200크레딧을 남겨 둡니다. 그래서 잔액이 약 210크레딧
    미만인 키는 건너뜁니다.

(2) Gemini 키

    sudo nano ops/secrets/gemini-key

  - Gemini 키를 붙여넣고 Ctrl+O → Enter → Ctrl+X


[5단계] 업데이트 실행 (한 줄 전체를 복사)
-----------------------------------------

    sudo bash ops/update_online_server.sh main --open-signup --per-account 3 --per-day 1000 --craft-day-limit 30 --max-credits 10 --welcome-stars 150

작은 서버라 몇 분 걸립니다. 끝에 /health 결과가 한 줄 나오면 끝입니다.

옵션 뜻 (숫자만 바꿔 다시 실행하면 규칙이 바뀝니다)
- --open-signup        : 초대 코드 없이 가입
- --per-account 3      : 계정 하나당 제작은 평생 3번
- --per-day 1000       : 계정별 하루 한도는 사실상 없음 (평생 3번이 먼저 걸림)
- --craft-day-limit 30 : 서버 전체 하루 제작 30번까지 (크레딧 보호)
- --max-credits 10     : 제작 1번에 Tripo 최대 10크레딧
- --welcome-stars 150  : 새 계정이 별씨 150개로 시작


[6단계] 성공 확인
-----------------
마지막 줄에 다음 글자들이 보이면 성공입니다.

    "version":"0.10.0"
    "studio_tripo_enabled":true
    "studio_llm":"gemini"
    "open_registration":true
    "tripo_keys":2   (등록한 Tripo 키 개수)

웹 브라우저로 https://34-28-65-113.sslip.io/health 를 열어도 같은 내용을 볼 수 있습니다.


[7단계] 심사위원·친구에게 보내기
--------------------------------
이 링크 하나만 보내면 됩니다.

    https://github.com/NormalMan0228/tripo_s1/releases/tag/v0.10.0

→ Tripothon_v0.10.0_Windows.zip 을 받아 압축을 풀고 Tripothon.exe 실행
→ 계정 만들기 (아이디 + 비밀번호만)
→ 마을에서 C 키 → 만들고 싶은 물건을 글로 적기 → 견적 확인 → 제작 확정


[문제가 생기면]
---------------
- 6단계 글자가 안 보일 때: 아래 명령의 출력을 복사해 Claude에게 보여 주세요.
  (키 값은 출력되지 않습니다)

    sudo docker compose --env-file ops/production.env -f ops/compose.yaml -f ops/compose.gcp-free.yaml -f ops/compose.tripo.yaml -f ops/compose.gemini.yaml logs api --tail 80

- 제작이 실패하고 잠시 뒤 다시 되는 경우: Gemini 무료 등급의 분당 한도입니다. 정상입니다.
- 키를 바꾸거나 추가하고 싶을 때: 4단계에서 파일만 고친 뒤 5단계 명령을 다시 실행합니다.
  (키를 지우면 그 키로 만들던 물건은 끝낼 수 없으니, 진행 중인 제작이 없을 때 지우세요.)
- 가입을 잠시 막고 싶을 때: 5단계 명령에서 --open-signup 을 --invite-only 로 바꿔 실행합니다.
  (게임에는 초대 코드 칸이 없으므로 그동안은 새 가입이 안 됩니다)

작업이 끝나면 메모장에 붙여 둔 키는 지워 주세요.
