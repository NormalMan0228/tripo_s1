## 영상을 3D로 바꾸는 단계

- **얼굴:** MediaPipe로 ARKit 52 값을 뽑는다. 무료이고 자동이지만 사람과 실사풍 얼굴에서만 된다. 아에이오우는 Audio2Face-3D로 음성에서 만든다. 애니·카툰은 추적기가 실패하므로, 레퍼런스 이미지의 입·눈 윤곽을 재서 맞춘다.
- **몸:**
  - Rokoko Vision: 월 30초 무료, $10에 600초.
  - QuickMagic: 손가락까지 잡힌다.
  - Move One: 월 $18에 60초.
  - Uthana: API 제공, 초당 $0.05. 상업 사용은 월 $100부터.
  - 같은 클립을 여러 도구에 넣어 직접 비교해야 한다. 독립 비교 자료가 적다.
- **괴물:** 영상에서 3D로 바꾸는 실용 도구는 없다. 자동 리그 프리셋과 Cascadeur 네발 포징으로 다듬는다. 덩어리형은 셰이프 키나 절차적 동작으로 만든다.

## 추천 조합 (캐릭터 1명)

- **얼굴:** 정지 이미지와 LivePortrait를 쓴다. 비용은 약 $0이다.
- **몸 10동작:** Kling Motion Control 720p로 만든다. 10동작 × 4회 × $0.55 ≈ $22이다. 이어서 Rokoko나 QuickMagic로 3D로 바꾼다.
- **괴물:** Tripo 프리셋을 쓴다(동작당 10 크레딧). 특별한 동작만 싼 영상을 참고한다.
