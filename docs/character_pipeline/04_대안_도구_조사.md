출처는 Gemini 답변 두 개입니다. 공식 판매·문서 페이지, GitHub 저장소, CG Channel 기사로 검증했습니다(링크는 아래). Rigify만 로컬 Blender 4.5.3에서 직접 시험했습니다.

## 결론
- **Faceit이 GUI로 하는 일을 무인으로 재현할 수 있습니다.** 순서는 다음과 같습니다.
  1. 우리 자동 기준점으로 Rigify 얼굴 메타리그를 맞춥니다.
  2. 무인으로 리그를 생성합니다(검증됨).
  3. 한 번 만든 52개 자세 라이브러리를 적용합니다.
  4. 셰이프키로 굽고 glTF로 내보냅니다.
  - 굽기 방법은 MIT인 ARKit-Creator 코드를 참고합니다.
  - 자세 라이브러리는 ShapeKeyGen(15달러, GPL)의 자세 데이터를 참고할 수 있습니다.
- **눈꺼풀**은 Rigify 눈꺼풀 뼈로도 Tripo의 두꺼운 띠 문제는 같습니다. T1 눈꺼풀 부품 방식이 우선입니다.
- **몸**은 UniRig(로컬, MIT)와 Tripo rig API(이미 쓰는 서비스)를 시험합니다. 시험할 때마다 리깅 전후 정점 수와 위치를 비교해 원본 유지를 확인합니다.
- **Audio2Face**는 표정 키가 생긴 뒤 립싱크 구동용으로만 씁니다.
