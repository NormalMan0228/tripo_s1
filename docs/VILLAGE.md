# 물결빛 마을 생활 · 0.7

마을 지형 범위를 26×26에서 72×68로 넓혔다. 중앙 광장·공방·생존 관문을 유지하고, 서쪽의 약 0.55m 높이 텃밭, 과수원, 동쪽 강과 두 다리, 약 3m 높이 북쪽 능선, 남쪽 모래 해변을 연결했다. 높이 변화는 실제 충돌 지형이며 캐릭터와 카메라가 경사를 따라 이동한다.

## 실행과 조작

기존 게임을 닫고 사용하던 패키지의 `StopServer.cmd`로 구버전 서버를 종료한 다음 `builds/Tripothon_Demo_07/Play.cmd`를 실행한다. 이 버전은 protocol 4다. 저장 DB를 삭제하지 않는다. 휴대용 서버의 저장 위치는 기존과 같은 `%LOCALAPPDATA%/TripothonDemo/server-data`다.

- WASD 이동, Shift 달리기, E 근처 밭·채집물·낚시터·NPC와 상호작용.
- Tab: 마을 지도. 목적지를 누르면 금빛 표식과 거리 안내가 생긴다.
- B: 생활 창고, 잎전, 수확물, 낚시 도감.
- I: 기존 생성 물건 보관함/공방. 장식 배치는 중앙 마을의 기존 구획을 사용한다.
- 낚시 중 E: 챔질. Esc: 대화/생활 창 닫기. M: 음소거.

## 생활 흐름

텃밭 6칸 중 하나에 씨앗을 심고 물을 한 번 주면 순무는 90초, 호박은 150초 뒤 수확할 수 있다. 각 밭에서 2개씩 수확한다. 물주기 이후 성장 시간은 서버 시계로 계산하므로 재접속과 탐험 중에도 성장한다. 추가 물주기로 시간을 줄이거나 수확 요청을 반복해 복제할 수 없다.

처음에 순무 씨앗 3개, 호박 씨앗 1개, 미끼 5개, 잎전 12개를 받는다. 공용 물뿌리개와 낚싯대는 자동으로 사용한다. 씨앗 가게에서 순무 씨앗은 2잎전, 호박 씨앗은 4잎전, 미끼는 1잎전이다. 잎전을 다 써도 과수원/향초밭의 무료 채집과 판매로 다시 시작할 수 있다.

낚시는 미끼 하나를 소모한다. 5~8초 뒤 금빛 입질 신호가 오며 3.5초 안에 E/챔질 버튼을 누르면 잡는다. 너무 빠르거나 늦으면 물고기를 얻지 못한다. 호수와 바다에서 강농어·은빛 도미를 잡을 수 있고, 바다에서 도미가 나올 확률이 더 높다. 획득 수량은 도감에 남으며, 판매해도 도감 기록은 유지한다. 창을 닫아도 미끼는 환불되지 않고 던져 둔 찌는 시간이 지나면 만료된다.

사과는 60초, 향초는 45초마다 2개씩 채집할 수 있다. 개별 나무마다 별도 보상을 지급하는 방식이 아니라 계정별 과수원/향초밭 재생 시간이다. 마을 식탁 의뢰는 순무 2개와 강농어 1마리를 받아 20잎전을 지급한다. 계정당 UTC 날짜별 한 번이다.

판매 단가: 순무 3, 호박 6, 강농어 4, 은빛 도미 8, 사과 2, 향초 1잎전. **잎전은 별씨/API 크레딧으로 변환되지 않는다.** 기존 생존 보상·생성·거래 경제와 별개인 마을 생활 재화다.

농부 단비는 씨앗과 생활 경제를, 낚시꾼 해루는 낚시를 설명한다. 기존 3명과 합쳐 NPC는 5명이다. 북쪽 종탑은 소리/피드백, 동쪽 전망대는 넓은 카메라 보기로 상호작용한다. NPC 일과·주거·호감도나 계절/날씨는 이번 구현에 포함하지 않았다.

## 변경 파일과 완료 기준

| 파일 | 역할 |
| --- | --- |
| `game/scripts/town.gd` | 높이 지형/물/다리/텃밭/과수원/해변/전망대, 성장 단계와 낚시 찌·줄 |
| `game/scripts/village_life.gd`, `town_map.gd` | 생활 UI, 지도·목적지 안내, 근접 상호작용, 서버 응답 표시 |
| `game/scripts/main.gd`, `player.gd`, `world_detail.gd` | 새 마을 연결, NPC/입력, 도구, 기존 중앙 마을 유지 |
| `server/homestead.py`, `app.py`, `models.py`, `database.py` | 계정별 상태·성장·낚시·가게·의뢰, 입력 제한과 원자적 저장 |
| `server/tests/test_homestead.py`, `game/tests/village_life.gd` | 권한·중복·시간·재화·재접속 및 실제 물리 이동/90초 성장/낚시 검사 |

검사 명령은 `tools/test.ps1 -Capture -Village`이며, 배포본은 `-Packaged -PortableServer`를 더한다. 새 QA DB/8766 포트를 사용한다. 실제 걷기→심기→물주기→낚시/채집→성장 대기→수확→판매→재로그인까지 통과해야 완료다. 지형/UI/실제 성장 테스트와 서버 시계를 제어하는 단위 검사를 구분한다.

## 저장과 서버 경계

새 `homesteads` 테이블에 소유 계정의 생활 상태 JSON을 저장한다. 기존 DB에 테이블을 추가하며 기존 계정/별씨/물건/탐험은 변환하지 않는다. 모든 변이는 인증, 서버가 정하는 소유자, 버전 비교, request_id 중복 방지, DB 트랜잭션을 거친다. 성장/입질/재생/배달 날짜와 구매·판매량을 클라이언트가 정할 수 없다.

마을 보행과 근접 UI는 기존처럼 로컬이다. 서버가 마을의 실제 이동 경로나 현장 접근을 증명하는 구조는 아니므로 직접 API를 호출하는 자동 플레이까지 차단한다고 주장하지 않는다. 서버는 생활 자산의 소유권·수량·시간·중복 지급을 검증한다. 실시간 멀티플레이/공개 운영용 이동 검증은 별도 작업이다.

이번 작업은 기존 Scenario 캐릭터·공방 아트를 재사용하고 지형과 생활 도구를 Godot에서 구성했다. 추가 Scenario CU나 유료 Tripo 생성 요청은 사용하지 않았다.
