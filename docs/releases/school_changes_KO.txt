Villagen 학교판 바뀐 점
=======================
새 버전은 맨 위에 적습니다. 형식: "== 버전 (날짜)" 줄 다음에 "- " 로 시작하는 한 줄씩.
내려받기 주소는 학교 공지로 안내합니다(저장소에는 적지 않음).

== 0.11.5 (2026-10-14)
- 이번 버전만 한 번 새로 설치해 주세요. 다음 업데이트부터는 게임이 켤 때 스스로 패치를 받아 적용함 (다시 설치 불필요, 받다가 끊겨도 이어 받기)
- 고침: 한글을 치면 앞 글자가 다음 글자로 덮어써져 한 글자만 남고, 로그인 칸에서는 글자가 사라지던 문제 (Windows 새 한국어 입력기와 게임 엔진의 충돌, 엔진에 공식 수정을 넣어 다시 만듦)
- 고침: Enter나 Esc를 누른 뒤 입력 칸이 글자를 받지 않던 문제. Esc를 누르면 입력 칸에서 빠져나옴
- 비밀번호 칸은 영문만 받고 "한/영 키로 바꿔 주세요" 안내가 뜸
- 입력한 글자가 사라지는 것이 보이면 게임이 Windows 입력기 설정 방법을 알려 줌
- 로딩 화면이 멈추지 않고 계속 움직이며, 별씨 둘레의 고리가 실제 진행률을 보여 줌
- 집에서 마을로 나갈 때 약 11초 → 약 2초. 주민 집·탐험에서 마을로 돌아올 때도 1초 넘게 빨라짐 (마을을 두 번 만들던 문제 고침)
- 게임을 켜면 검은 화면 없이 약 1초 만에 로딩 화면이 뜨고, 타이틀까지 약 8초 → 약 5초 (처음 실행은 11초 → 7초)
- 섬을 미리 지어 두고 보이지 않는 그림 크기를 줄여서 메모리 약 3분의 1, 게임 파일 약 520MB 절약
- 다른 플레이어가 끊기거나 순간이동하지 않고 부드럽게 걸어 다님 (마을·방문·함께 탐험·방)
- 마을 주인이 나가거나 게임이 꺼지면 방문 중인 친구가 자기 마을로 돌아가고 이유가 뜸 (예전에는 혼자 남아 있었음)
- 친구가 게임을 끄면 내 화면에서도 바로 사라짐. 방문이 1시간 지나면 끊기던 제한 없앰
- 게임을 켜자마자 버전을 확인하고, 새 버전이 있으면 바로 업데이트 화면을 보여 줌
- 서버 점검이 시작되면 모두 타이틀로 안전하게 나가고 점검 안내와 남은 시간이 뜸
- 업데이트·로그아웃 화면 영어·중국어 지원

== 0.11.4 (2026-10-14)
- 만든 물건의 충돌이 실제 모양을 따름: 상자 하나 대신 다리·상판·등받이 같은 여러 조각으로 막혀서, 아치 밑이나 높은 탁자 아래 빈 곳을 지나가고 물건에 바짝 다가설 수 있음
- 모양 바꾸기(가로·깊이·높이·크기·좌우 반전)를 하면 충돌 조각도 같이 늘어나고 뒤집힘
- 제작 대기 화면: 설계 → 그림 → 3D 부품 n/m → 완성 단계 표시와 실제 진행률(%)
- 그림·견적이 준비되면 알림과 효과음 (마을에서 창을 닫아 둬도)
- 놓을 때 깜빡임 없이 그대로 자리 잡고, 반짝임·고리·빛과 함께 "뿅" 등장. 옮기면 먼지와 쿵 소리
- 한 번 받은 모델은 다시 받지 않음 (같은 물건을 여러 번 내려받던 문제)
- 고침: 두 글자 이름("의자")으로 만들면 로그인 오류 문구가 뜨며 실패하던 문제
- 고침: Tripo 작업이 끝나지 않으면 서버 전체 제작이 멈추던 문제 (부품당 시간 제한 후 별씨 환불)
- 고침: 확인이 필요한 제작이 창에서 계속 돌기만 하고 새 제작을 막던 문제
- 고침: 상태 확인이 한 번 실패하거나 게임을 다시 켜면 제작 추적이 끊기던 문제
- 고침: 큰 가구 부품을 받다가 시간 초과로 실패하던 문제
- 고침: 방에서 저장하지 않았는데도 "꾸민 모습이 저장됐어요"가 뜨던 문제
- 고침: 마을 대화와 로그인 칸에서 Enter를 한 번 누른 뒤 다시 클릭해야 글자가 써지던 문제 (한글 입력이 끊기던 원인)
- 고침: 비밀번호 칸에서 한글 모드면 비밀번호가 한글로 입력되던 문제 (비밀번호 칸은 영문 입력)
- 친구 마을·집을 방문했을 때 집주인이 가구를 쓰거나 옮겨도 가구를 다시 불러오지 않고 바뀐 것만 반영 (끊김 감소)
- 고침: 연결이 잠깐 끊기면 방문 중인 마을의 가구가 모두 사라지던 문제
- 만든 물건이 종류에 맞게 살아 움직임: 시계·문·상자·수납장·서랍·조명·랜턴·촛불·선풍기·풍차·물레방아·화분·깃발·풍경·흔들의자·오르골·지구본·화면·간판·침대·의자 등 22종의 기본 동작이 자동으로 붙음 (상호작용 창에서 고칠 수 있음)
- 시계는 내 PC의 실제 시각에 맞춰 바늘이 돌고, 초침이 1초마다 째깍 움직임 (바늘은 게임이 만들어 Tripo 크레딧이 들지 않음)
- 새 동작: 서랍 밀고 당기기, 촛불 일렁임, 흔들의자 흔들기, 날개 돌기, 한 칸씩 돌기
- AI가 만든 동작은 저장해 두고, 같은 설명이면 별씨·AI 호출 없이 다시 씀
- 크레딧 한도를 넘는 설계는 실패 대신 한 덩어리로 줄여서 만듦
- 화면에 보이지 않는 물건은 동작 계산을 쉬어서 가벼움
- 색 입힌 움직이는 시계를 학교 서버 한도 안에서 20크레딧에 만들 수 있음. 시계는 "움직이지 않는 가구"를 골라도 바늘 있는 시계로 만들어짐
- 시계 바늘이 스타일에 맞게 다듬어짐: 스페이드 시침, 화살표 분침, 균형추 달린 초침, 가운데 덮개 (앤티크는 놋쇠·무쇠, 아늑한 동화는 나무, SF는 빛나는 청록)
- 마을에 놓은 의자·벤치·침대에도 앉고 누울 수 있음 (집 안과 같은 동작, E·Esc·걸어서 일어나기)
- NPC 이름표가 도로에 가려지지 않음
- 대화창이 NPC 일러스트를 가리지 않음 (그림마다 보이는 범위에 맞춰 배치, 화면 크기 140%에서도 머리가 잘리지 않음)
- 밤에는 그림자 주민, 아침·낮에는 같은 길과 일과를 지내는 색 있는 마을 주민 15명 (해 질 녘·새벽에 한 명씩 천천히 바뀜)
- 건물 출입·로그인·모험 출발과 귀환·계단 이동이 모두 같은 부드러운 페이드로 바뀜
- 로딩 화면: 장소 이름, 빛 알갱이, 도는 별씨, 팁 한 줄. 게임 시작 로딩은 처음 표지 그림
- 고침: 집 안 계단·사다리를 오를 때 걷는 동작 없이 T자세로 미끄러지던 문제
- 고침: 급하게 방향을 틀거나 지그재그로 걸을 때 다리가 꼬이고 하반신이 꺾이던 문제
- 고침: "가람 · 시인와 대화"처럼 이름에 따라 조사가 틀리던 문제 (와/과)
- 고침: 앉으면서 누른 E가 가끔 무시되던 문제
- NPC에게 만든 가구를 선물할 수 있음: 대화 → 선물하기 → 가방에서 고르기. 하트 말풍선·꽃잎·종소리와 함께 고마워함 (집에 사는 주민 13명)
- 선물 받은 가구는 몇 분~몇 시간 뒤 NPC가 자기 집에 놓고, 가끔 옮기거나 바꾸거나 보관함에 다시 넣음 (내 마을마다 따로, 방문자도 같은 모습)
- NPC 호감도 하트 0~4 (하루 첫 선물이 가장 크게 오름)
- 어디서나 같은 캐릭터 모습: 마을·집 안·친구 방문·협동 탐험·옷장 미리보기·친구 화면이 모두 같은 외형을 쓰고, 꾸미면 0.2초 안에 내 화면과 친구 화면에 반영됨 (뾱 효과와 반짝임)
- HUD 초상화가 내 캐릭터 얼굴을 직접 그려 모자·옷 색까지 반영
- 고침: 로그인 직후나 집에서 나올 때 기본 여행자 모습으로 나오던 문제
- 고침: 집 방문자·협동 탐험 동료의 모습이 들어올 때 모습으로 굳어 있던 문제
- 캐릭터를 다시 만드는 시간이 0.2~0.36초에서 약 0.002초로 줄어 옷장 클릭·다른 플레이어 등장 시 끊김이 사라짐
- 고침: 화면 페이드가 겹치면 가끔 멈추던 문제
- 처음 받은 의자나 예전에 만든 물건도 NPC에게 선물할 수 있음 (집 안에 맞는 크기로 놓임)
- 하트가 오를 때마다 NPC가 "나의 우편함"으로 편지를 보냄 (안 읽은 편지가 있으면 우편함 깃발이 올라감, 지난 편지 다시 읽기)
- 하트 4가 되면 NPC가 답례 선물을 보냄 (가방에 들어오고 놓거나 다시 선물 가능)
- NPC 집마다 보관 상자: 아직 꺼내 놓지 않은 선물 목록을 볼 수 있음 (방문자도), 등대에 놓을 자리 추가
- 고침: 집 안 대화에서 숫자 키를 누르면 선물 대화가 닫히던 문제
- 고침: 게임을 끌 때 엔진이 충돌(0xC0000005)하던 문제 (설정 알림에 등록한 함수가 종료 순서상 먼저 지워지던 것)
- 고침: 끌 때 집 음악 재생이 정리되지 않고 남던 문제
- 고침: 가구를 놓으려는 순간 가방 갱신이 늦게 끝나면 놓던 가구가 취소되던 문제

== 0.11.3 (2026-10-12)
- 스타일 9종(판타지 RPG, 아늑한 동화, 실사, 애니메이션, 앤티크, 한옥 전통, 미래 SF, 로우폴리, 숲속 자연)과 크기 5단계(자동, 0.6m, 1.2m, 1.8m, 2.4m)를 골라 제작
- 기본 스타일이 RPG 소품풍으로 바뀌고, 한 덩어리 가구가 원래 비율 그대로 나옴
- 자유 회전: 놓을 때 R 15°, Alt+R 1°, 마우스 휠 5°, 화면의 회전 버튼. 이미 놓인 물건도 다시 돌리거나 옮기기
- 모양 바꾸기: 가방·보관함에서 가로, 깊이, 높이, 전체 크기(50~200%)와 좌우 반전
- 상호작용: 빙글 돌기, 흔들흔들, 통통 튀기, 불 켜기·끄기, 빛나기, 색 바꾸기, 계속 돌기, 부품 열고 닫기를 클릭/다가가면/멀어지면/항상에 맞춰 조합. 글로 설명하면 AI가 동작을 만들어 줌(별씨 5, 하루 10회). 앉기·눕기
- 색칠 작업대 새 디자인(도구 막대, 도구별 옵션, 붓 미리보기, 세로 슬라이더, 레이어 썸네일)
- 시작 화면: 켠 시각에 따라 키아트 3종(아침, 해 질 녘, 밤 등불)
- 밤 낚시와 하루 한 번 배달 주문이 내 PC의 지역 시간을 따름
- 새 버전 알림, 서버 점검 30분 전 예고와 점검 대기 화면
- 고침: 움직이는 부품 가구에서 칠 위치가 어긋나던 문제와 UV 이음새 틈
- 고침: 가구 근처에서 화면이 멈칫하던 문제
- 고침: 집에 들어가면 다른 캐릭터가 잠깐 보이거나 옷장 모습이 늦게 적용되던 문제
- 고침: 게임이 켜지는 동안 다른 창을 누르면 한글 입력 때문에 꺼질 수 있던 문제
- 고침: 방 보관함에서 물건을 고르면 모양이 늘어나던 문제

== 0.11.0 (2026-10-08)

- 제작 화면이 서버 한도 안의 옵션만 열고 오류를 알기 쉬운 문장으로 보여 줌
- 색 입힌 물건의 텍스처를 1K로 줄이고 압축(그래픽 메모리 약 1/4~1/7)
