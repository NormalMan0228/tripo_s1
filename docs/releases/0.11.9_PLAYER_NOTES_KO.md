# Villagen 0.11.9 바뀐 점

2026-10-16 메인 서버. 0.11.7·0.11.8을 설치했다면 게임을 켜면 스스로 업데이트됩니다.

- 캐릭터 8명 중에서 고르고, 머리·피부·옷·장식 색과 모자로 꾸미기. 기존 계정도 다음 접속 때 한 번 고르게 돼요
- 표시 이름을 따로 정할 수 있음(하루 한 번 바꾸기). 채팅과 이름표에 보여요
- 탐험 몬스터 18종이 새 모습으로, 종마다 다른 울음과 공격 소리
- 마을 가방: 칸과 탭, 물건 3D 미리보기
- 농사: 자라는 단계가 보이고 물을 주지 않으면 목말라해요. 무·감자·토마토·옥수수 추가
- 손에 들고 다니기 7종(창고의 '들기'), 다른 사람에게도 보여요
- 의뢰 게시판의 '오늘의 부탁', 주민이 보내는 편지, 가게 창에서 사고팔기
- 보니·솔 주민과 요일·휴무·장날 일과
- 꾸미기: 놓은 물건 우클릭 메뉴, 방 벽·천장·다른 물건 위에 놓기, 큰 물건은 문 앞·다리·길에 놓을 수 없음
- 집: 방문이 지나갈 때 열리고, 다시 접속하면 있던 자리에서 시작. 오래 쉬었으면 침대에서 일어나요. 집주인은 문을 잠그거나 손님을 내보낼 수 있음
- 제작: 기능 종류(의자·조명·상자 등)를 직접 고를 수 있음. 안 되는 요청은 이유를 알려 주고, 사진 방향을 바로잡아요
- 제작: '움직이는 캐릭터로 만들기'를 고르면 뼈대와 기본 동작(대기·걷기)이 함께 붙어 제자리에서 움직여요(제작 비용에 포함)
- 탐험 모닥불: 곁에 있으면 체력이 회복되고, 떠난 뒤에도 잠깐 공격이 강해져요
- 효과: 탐험 휘두르기·타격·채집·모닥불·회복, 마을 반딧불과 꽃잎, 도구가 닿는 순간의 효과
- 성능: 마을에서 멈칫하던 순간을 줄이고(최악 프레임 약 절반), 섬 소품 LOD를 되살려 그리는 양을 줄임
- 친구가 아닌 사람에게는 가까이 있을 때 귓속말 요청을 보낼 수 있음(수락해야 대화)
- 고침: 귓속말 요청 뒤 다시 보낸 말이 전체 채팅으로 나가던 문제, 받침 위 의자에서 일어설 때 몸이 솟던 문제
