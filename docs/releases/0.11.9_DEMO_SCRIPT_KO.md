# Villagen 0.11.9 — 10분 시연 대본

타이틀 → 캐릭터 선택 → 마을 → 문장으로 물건 만들기 → 배치 → 친구 집 → 의뢰 게시판 → 모닥불과 탐험 → 몬스터 순서로 진행합니다. 아래 시간에는 이동과 설명이 모두 포함됩니다.

**확정**은 통합본에 반영된 기능이며 배포 완료 표시는 아닙니다. **예정**은 통합·화면 연결·활성화 확인이 남은 기능입니다. 예정 기능은 리허설에서 실제 동작한 경우에만 조작하며, 소개할 때도 예정임을 밝힙니다. 준비 화면이 없다면 해당 기능은 말로만 짧게 소개하고 기존 기능으로 이어갑니다.

## 시작 전에 준비하기

- 첫 이야기와 탐험 튜토리얼을 마친 진행용 계정을 준비합니다. 캐릭터 첫 선택은 별도 체험 계정이나 리허설 녹화로 보여 주고, 마을 단계에서 진행용 계정으로 이어갑니다.
- **[예정] 캐릭터 8명:** 현재 선택 화면은 기존 4명까지이며, 8명 선택과 꾸미기의 화면 연결은 아직 남아 있습니다. 실제 8명 화면이 준비되지 않았다면 기존 옷장 미리보기를 사용합니다.
- **[확정] 제작과 배치:** 가방에 완성된 작은 의자 한 개를 미리 준비합니다. 제작 시연에는 같은 종류의 문장을 씁니다. 모의 제작 예제를 쓰는 경우에는 시작할 때 예제임을 밝힙니다.
- **[확정] 친구 집:** 보조 계정과 미리 친구를 맺고, 보조 계정은 집 안에서 기다립니다. 집 잠금은 풀어 두고, 방문 뒤 자기 마을로 돌아오는 동선도 연습합니다.
- **[예정] 마을 생활:** 물 줄 작물, 읽지 않은 주민 편지, 받을 수 있는 게시판 부탁을 준비합니다. 입주는 현재 단비가 대상이며 기본적으로 꺼져 있으므로, 입주가 끝난 준비 화면을 사용합니다. 가게는 해당 주민이 영업 중일 때 확인합니다.
- **[예정] 모닥불 버프:** 버프를 지원하는 시연판에서 해당 기능이 켜졌는지 확인하고 새 탐험으로 연습합니다. 기존 보호 방식이 기본이며, 진행 중이던 탐험에는 새 효과가 바로 적용되지 않습니다. 체력·기력이 조금 줄어든 상태에서 회복과 몸 주위 온기 효과를 확인하고, 확인하지 못했다면 버프를 시연하지 않습니다.
- **[예정] 새 몬스터:** 18종의 새 모델이 시연판에 실제 포함됐는지 확인합니다. 마지막 구간에서 보여 줄 몬스터가 나오는 탐험 동선과 리허설 영상을 준비합니다. 열여덟 종을 모두 현장에서 만나는 일정은 아닙니다.
- **[확정] 소리:** 음악과 효과음이 들리는지 확인합니다. **[예정]** 새 생활 효과음은 연결된 소리만 들려줍니다.
- 전체를 한 번 재고 연습합니다. 제작은 4:00, 친구 방문은 6:15, 게시판은 7:15에 다음 단계로 넘어갑니다. 전환이 늦으면 준비한 화면이나 영상으로 같은 시간표를 지킵니다.

## 제작이 길어질 때의 전환 멘트

“아직 만드는 중이네요. 기다리는 동안 할 수 있는 일을 보여 드리려고, 미리 완성해 둔 의자로 배치부터 이어갈게요.”

실제 제작을 새로 반복하지 말고 진행 중인 작업은 그대로 둡니다. 완성 알림이 와도 현재 설명을 마친 뒤 짧게 알리며, 10분 일정은 늘리지 않습니다. 모의 제작 예제는 제작 흐름을 설명하는 용도로만 쓰고, 실제 생성 결과나 소요 시간의 증거로 소개하지 않습니다.
