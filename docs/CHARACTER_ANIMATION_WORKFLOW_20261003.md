# 캐릭터 생성과 애니메이션 제작 과정

**최신 이미지 수정:** 신체는 머리·몸·손, 재킷은 소매 포함, 바지는 주머니 포함,
벨트는 버클 포함으로 제작 단위를 줄였습니다. [수정 이미지 6장](../art/references/explorer_b_modular_v1/02_parts_simple_v2/simple-parts-v2.jpg)은 검토 대기 중입니다.
이전 19종 참조와 60개 계획 단위는 과거 안입니다. 새 3D·리깅은 아직 시작하지 않았습니다.

기준일 **2026년 10월 3일 한국 시간**. Tripothon의 B형 탐험가를 기준으로,
실제로 수행한 제작 과정과 현재 결과물, 후속 제작 순서를 정리합니다.

<a id="summary"></a>
## 요약

**다음 제작은 신체·의상·장식을 독립적으로 만들고, 좌우 대칭과 접합을 검수한 뒤 리깅으로 진행합니다.**
[확정한 부위별 제작 기준](CHARACTER_MODULAR_PRODUCTION_STANDARD_20261003.md)에 상세 규격과 완료 기준을 정리했습니다.

**단계마다 사용자 검토를 받고 진행합니다.** 전신 2D 원안 v1은 “다음 단계로” 지시로
승인 기록을 남겼고, 현재 [부위별 2D 참조 19종·27장](CHARACTER_PART_REFERENCES_20261003.md)의
검토를 기다립니다. 새 3D 생성·UV·조립·리깅으로 자동 진행하지 않습니다.

현재 최신 **표면 분리 실험본**은 40개의 독립 메시와 41본, 영상에서 만든 몸 동작 6개를 가집니다.
Tripo가 몸체·재질·초기 몸 리깅을 만들었고, Blender에서 부위 분리와 동작 보정을 했습니다.
영상 기반 동작은 Scenario에서 생성한 영상을 MediaPipe로 추적한 뒤 Blender에서
캐릭터의 뼈 움직임으로 옮겼습니다. 영상 자체를 게임에 재생하는 방식은 아닙니다.

새로 만든 고밀도 손과 머리카락은 독립 실험 결과이며 아직 몸체에 결합하지 않았습니다.
얼굴 표정 리깅, 옷 안쪽 몸체와 의상 단면, 완성된 복장 교체는 남아 있습니다.
본 게임의 기존 71본 캐릭터와 최신 41본 제작 실험은 서로 다른 파일입니다.

**새로 확정한 제작 흐름**

전신 2D 원안 검토 → 부위별 다면 참조 → 신체·의상·장식 별도 생성 → 대칭·비율·접합·Sculpt
→ 변형용 토폴로지 → UV·베이크·텍스처 → 몸·손 리깅 → 얼굴 리깅
→ 동작과 전환 → GLB 내보내기 → Godot 검수

아래의 전신 생성·초기 리깅·표면 분리는 **이미 수행한 실험 기록**입니다.
옷을 입은 전신을 먼저 리깅하고 나누었던 순서를 새 제작의 표준으로 반복하지 않습니다.

참고 영상은 리깅 이후 동작 제작에 사용합니다. 변형이 잘못되는 손·얼굴은
모션을 더 만드는 것에 앞서 메시와 리깅을 보완해야 합니다.

## 지금까지 수행한 캐릭터 제작 실험

### 컨셉과 기준 이미지

B형 탐험가의 체형, 갈색 단발, 노란 재킷, 밝은 셔츠, 카고 바지와 부츠를
기준으로 삼았습니다. 생성에는 정면 이미지, 동작 참고 영상에는 측면 이미지를
사용했습니다. 기록된 입력은 `art/references/explorer_b_v5/front.png`와 `side.png`입니다.
앞으로 새 부품을 만들 때도 이 기준과 손목·목·발목의 치수를 대조해야 합니다.

### Tripo 메시와 재질 생성

Tripo **P2-20260801**에 기준 이미지를 넣어 전신 메시와 재질을 생성했습니다.
요청은 `face_limit=40000`, `texture=true`, `pbr=true`,
`texture_quality=detailed`, `orientation=align_image`입니다.
face limit은 요청값이며 실제 최종 삼각형 수와 같은 숫자는 아닙니다.

이 단계의 결과는 표면 형상, UV와 텍스처입니다. 해부학적으로 완전한 몸체,
독립된 의상의 안쪽, 모든 얼굴 표정이나 관절 구조가 자동으로 완성된 결과로
보지는 않습니다. 먼저 얼굴·손·복장 형상과 분리 경계를 확인합니다.

### 초기 몸 리깅

Tripo 리깅 **v1.0-20240301**, `biped`, `spec=tripo`, GLB 출력을 사용해
41본 몸 리그와 스킨 가중치를 얻었습니다. 뼈는 관절의 위치와 관계를 정의하고,
스킨 가중치는 각 메시 정점이 어느 뼈를 얼마나 따라갈지 정의합니다.

현재 제작 실험의 41본에는 개별 손가락 움직임과 완성된 얼굴 표정 구조가 없습니다.
본 게임의 71본 B에는 별도로 보강한 손가락 구조가 있으므로 이 둘을 혼동하지 않습니다.

### 부위별 메시 분리

Tripo **mesh segment v2.0-20260430**, detailed,
`split_by_connectivity=true`로 87조각을 얻었습니다.
이 조각에는 신발의 작은 장식도 포함되어 있어 그대로 의미 있는 87부위로 사용하지 않았습니다.

후속 Blender 작업에서 조각을 이미지로 확인하고 의미 단위로 묶었습니다.
분할 조각의 삼각형을 애니메이션 원본과 대응시킨 뒤, 원본의 위치·UV·가중치를
각 독립 메시로 옮겼습니다. 좌우 바지와 팔·손 경계도 나눠 **40개 오브젝트**를 만들었습니다.

전체 41,778삼각형을 누락과 중복 없이 유지했고, UV·스킨 가중치 차이는 0입니다.
기존 6개 동작에서 각 5개 시점, 총 30개 시점을 비교했을 때 원본 대비 정점 위치 차이와
공유 경계 벌어짐은 모두 0이었습니다. 이는 검사한 동작과 시점의 결과이며,
의상을 교체하거나 극단적인 새 자세를 검수했다는 뜻은 아닙니다.

머리·손·옷을 따로 선택할 수 있는 상태와, 완전한 부품 교체 캐릭터는 다른 제작 단계입니다.
현재 의상에는 숨겨진 몸체와 안쪽 단면을 새로 만들지 않았습니다.

### Tripo 프리셋 실험

idle, walk, run을 요청했지만 최초 일괄 출력에는 run만 들어 있었습니다.
walk와 idle을 단일 요청으로 보완한 뒤, Blender에서 수평 루트 이동과 반복 경계를
정리했습니다. 자동 생성 요청이 성공했는지와 원하는 동작이 실제 파일에 있는지는
따로 확인했습니다. 이 프리셋 동작이 영상 기반 전용 동작으로 바뀐 것은 아닙니다.

### 영상 기반 동작

같은 측면 캐릭터 이미지와 동작 요청을 사용해 Scenario에서 **Seedance 2.0 Legacy,
PixVerse V6 I2V, Kling V3 I2V Pro** 영상 3종을 생성했습니다.
고정 카메라에서 제자리 걷기를 한 뒤 정지하는 요청이었으며 원본 길이는 각 약 5.04초입니다.
모델에 따라 출력 해상도와 실제 동작은 달랐습니다.

후속 변환은 다음 순서로 수행했습니다.

1. **MediaPipe Heavy 추적:** 몸 관절의 프레임별 위치를 추적합니다.
2. **채널 정리:** 추적 흔들림을 필터링하고 몸통·머리·허벅지·종아리·발·팔의 움직임으로 정리합니다.
3. **Blender FK 전이:** 추적한 동작을 캐릭터의 41본에 맞춰 옮깁니다. FK는 뼈의 회전으로 관절 사슬을 만드는 방식입니다.
4. **변형 보정:** 무릎과 팔 관절의 범위를 제한하고, 부츠의 실제 스킨 정점을 기준으로 몸 높이를 보정합니다.
5. **반복 구간 제작:** 영상에서 반복 가능한 구간을 골라 시작·끝 회전 차이를 구간 전체에 분산해 닫습니다.
6. **베이크와 재임포트:** 60fps로 뼈 키프레임을 저장하고 GLB를 내보낸 뒤 다시 불러와 검사합니다.

| 영상 원본 | 전체 시퀀스 | 반복 클립 | 기록된 보행 기준 속도 |
|---|---|---|---|
| Seedance 2 | 5.00초, 301프레임 | 0.7833초, 48프레임 | 약 1.49m/s |
| PixVerse V6 | 5.00초, 301프레임 | 1.5000초, 91프레임 | 약 0.69m/s |
| Kling V3 | 5.00초, 301프레임 | 1.2833초, 78프레임 | 약 1.02m/s |

기준 속도는 1.7m 게임 크기에서 지지하는 발의 이동으로 추정한 실험값입니다.
전체 시퀀스는 시작과 끝이 다른 **비반복 동작**이며, 반복용 클립과 구분합니다.
단일 측면 영상의 깊이는 추정·보정한 값이고 정밀한 다중 카메라 모션 캡처가 아닙니다.
이번 영상 추적에는 개별 손가락과 얼굴 표정이 포함되지 않습니다.

### 독립 손 동작

Scenario 손 참고 이미지 → Tripo 손 메시 → MediaPipe 21점 → Blender의 메시 깊이 조회
→ 손바닥과 손가락용 16본 → 자동 가중치와 정리 → 직접 작성한 완만한 쥐기 동작으로 진행했습니다.
공유 정점을 병합하고 가중치를 부드럽게 정규화해 초기 엄지 변형을 줄였습니다.

Blender 작성 구간은 30fps, 2.4초이고 Godot에서 가져온 동작 길이는 약 2.433초입니다.
이는 손 영상에서 전체 동작을 자동 캡처한 결과나 Tripo 모션 API 결과가 아닙니다.
실제 몸체의 손목 맞춤, 좌우 손 판별, 엄지 대립과 도구 접촉은 아직 남아 있습니다.

## 게임 속도와 동작 전환 검수

게임의 실제 수평 이동은 Godot의 캐릭터 모터 또는 서버 좌표가 담당합니다.
클립은 제자리 동작으로 만들고, 발의 주기와 재생 속도를 실제 변위에 맞춥니다.
루트 이동과 게임 이동이 함께 적용되어 두 번 움직이지 않도록 합니다.

영상 모션 실험에서는 GLB 재임포트 후 반복 시작·끝 회전 차이가 Blender에서 0°,
Godot에서 약 **0.04~0.06°**였고, **0.24초 블렌드**를 30fps와 60fps에서 검사했습니다.
최신 40부위 분리본에는 동일한 6개 동작을 유지했습니다. 분리본의 30시점 검사는
Blender 변형 비교이고, 분리본을 본 게임에 통합한 새 플레이 검사를 대신하지 않습니다.

본 게임 마을의 걷기와 달리기는 **2.8 / 4.5m/s**입니다.
영상 보행의 기준 속도 0.69~1.49m/s와 차이가 있으므로, 모든 클립을 고정 속도로
바로 적용하지 않습니다. 큰 속도 차이를 재생 가속만으로 해결하면 동작이 빠르게 보일 수 있어,
최종 걷기와 달리기는 보폭·주기·전환을 함께 검수해야 합니다.

기존 71본 B에는 게임에서 실제 변위에 따라 대기·걷기·달리기를 선택하고,
발의 접점을 보정하는 두 관절 IK가 있습니다. 41본 실험 캐릭터에 동일한 상세 IK와
손가락 보정이 모두 적용된 것으로 보지 않습니다. [본 게임의 확인된 범위](CONTROLLER_092.md).

최종 검수에는 대기 ↔ 걷기 ↔ 달리기, 급정지·회전, 벽 앞 정지, 경사·계단,
도구 사용과 중단, 건물 출입을 포함합니다. 반복 경계를 닫았다는 사실만으로 모든
전환과 접지가 자연스러워졌다고 판단하지 않습니다.

## 얼굴과 손의 후속 제작

얼굴은 **기준 얼굴 형상 → 눈꺼풀과 입 주변 토폴로지 → 눈알과 입 안 구조
→ 얼굴 리그와 표정 변형 → 영상 또는 음성에서 얻은 표정 모션** 순서로 제작합니다.
눈·눈꺼풀·입을 독립 오브젝트로 나눈 것만으로 얼굴 표정이 작동하는 것은 아닙니다.
Rigify 얼굴 메타리그는 준비했지만 현재 탐험가 얼굴에 맞추거나 바인딩하지 않았습니다.

Faceit은 표정 구조 준비, MediaPipe는 영상 추적, Audio2Face는 음성 기반 얼굴 동작의
조사 후보로 정리했습니다. 현재 설치·연결·완성된 얼굴 파이프라인으로 기록하지 않습니다.
웃는 얼굴을 별도 생성한 메시를 곧바로 표정 shape key로 사용한 것도 아닙니다.

손은 현재 몸체 손목에 맞는 치수, 관절별 변형용 면 흐름, 엄지 움직임과 좌우 대응을
먼저 확정합니다. 그 뒤 16본 독립 실험의 동작을 몸 리그와 연결해 걷기·달리기·도구 쥐기를
검수합니다. 새 헤어도 두상 맞춤과 목 회전 중 간섭을 확인한 뒤 통합합니다.
