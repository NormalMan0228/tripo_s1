Villagen — 2026년 10월 6일 작업 요약 (village + generate, 이전 작업명 Tripothon)
=====================================

1. 마을 생활과 실내 (커밋 4947d07)
-----------------------------------
- 주민의 하루: 주민 19명에게 각자 집과 침대가 있고, 시간대마다 일하고 쉬고 잡니다.
  불 꺼진 집은 잠겨 있고, 가게·특수 건물 안에는 NPC 방이 따로 있습니다.
- 실내: 건물마다 넓이·방 수·층수가 다르고 상호작용 물건이 늘었습니다.
  문마다 다른 효과음, 바깥 시간에 맞춰 바뀌는 창문.
- 그림자 주민 15명: 실루엣 NPC가 마을을 돌아다니며 대화합니다.
- 생활 콘텐츠: 밭 만들기, 낚시 미니게임과 도감, 채집,
  나무를 흔들면 3D 열매가 떨어짐, 필드 오브젝트 추가.
- 조작감: 걷기 프레임 5.8 → 3.9ms, 끊김 0. 이동 떨림·장면 전환 때 다리 꺾임·T자 포즈 수정.
  집에서 시작, 넓어진 계단, 가로등 자동 점등, 가리는 물체만 반투명,
  밖에서는 건물 내부가 안 보임, 결과를 문장 대신 시각 효과로 표시.

2. 설정·UI·몬스터·생존 맵·사운드 (커밋 6bd0a8b)
------------------------------------------------
- 설정: 그래픽, 사운드(버스 5개), 키 재설정, 게임플레이, 접근성.
- UI 1차 개편: 무료 라이선스 글꼴, 프레임, 아이콘, 효과음.
- 몬스터 5종 × 지역 3변형: Tripo 생성 → 자동 리깅 → 애니메이션.
- 생존 맵 3곳: Tripo 소품 35종과 지형 셰이더로 새로 만들고 구멍·최적화 처리.
- 사운드: 몬스터 울음, 전투, 주인공 기합, NPC 21명의 서로 다른 목소리.
- 필요 없는 파일을 지워 디스크 공간 확보.

3. 전용 UI 이미지·편의 기능 (커밋 58a7893, 버전 0.10.0)
-------------------------------------------------------
- 전용 UI 이미지 세트: Scenario(GPT Image 2)로 패널, 대화 상자, 버튼, 슬롯,
  미니맵 링, 아이콘 20종을 그려 게임 UI 조각으로 잘라 넣음.
- 배경 없는 대화 일러스트: 나루·소라·모루·해루 × 기본·웃음·놀람.
  대사에 따라 표정이 바뀌고, 그림자 주민도 배경 없는 실루엣.
- HUD 접기·펼치기: 패널마다 접기 버튼, U 키로 전체. 상태 저장.
- 이름 툴팁: 그림만 있는 UI에 마우스를 올리면 이름과 단축키 표시.
- 길 안내: 목표 줄이나 지도를 누르면 길 위 화살표, 목적지 빛기둥,
  미니맵 경로, 남은 거리 표시. 도착하면 효과와 함께 끝남.
